# MERGE - журнал (2026-11-12)

Сделано
- tools\build\merge_mods.py: отбор кандидатов заново по генератору mods.cfg без слияния (учтены исключения DEDUP-ACT), складывание записей в один .mod (формат 17, дельты про один sid складываются в порядке загрузки: значения - последний побеждает, ссылки и инстансы - последовательно как kmod.apply, change-флаг первого), объединение dependencies/references без самих исходников, манифест rules\merged_manifest.json (имя, путь, md5, число записей, md5 слитого файла, якорь позиции), секция "merged" в rules\excluded_mods.json (читает только mods_cfg.py; lo.py и catalog.py её не видят, пулы не меняются).
- Критерии кандидата: не KMM_, не ядро; в папке только .mod/.info/.img и превью в корне (нет ресурсов, подпапок, dll/json/lua); 1..499 записей; нет удалений записей; на мод никто не ссылается (dependencies/references/required_items); заголовок без хвоста.
- Эквивалентность: для каждого sid исходников цепочка "ваниль + все моды по порядку" (kmod.apply, strict для модов) с исходниками и с прочитанным из байтов KMM_Merged на их месте сравнивается по имени, значениям (с типом), ссылкам (с порядком), инстансам. Расхождение или нечитаемый файл - слияние не записывается, сборка падает. Исходник, у которого между ним и позицией слияния стоит мод, правящий тот же sid, исключается из слияния (фикс-пойнт); позиция - последний или первый исходник, берётся вариант с большим набором. Зависимости исходников должны стоять раньше позиции.
- Round-trip: KMM_Merged и каждый исходник write(read(x)) == x.
- Флаг rules\merge.json {"enabled": true}; false - генератор как раньше (735 строк).
- mods_cfg.py: merge_state/apply_merge; исходники убираются из списка, KMM_Merged ставится после якоря insert_after (запасной insert_before); check: md5 слитого файла = манифест (ошибка), исходник слит и стоит в списке (ошибка), зависимость на слитый мод считается зависимостью на KMM_Merged, изменился md5 исходника - предупреждение, мод возвращается в mods.cfg на своё место, KMM_Merged устарел до merge_mods.py --write (merge_mods.py сам пересчитывает набор по текущим md5).
- kmm_build.py: шаг merged (--write merged|all пишет build\KMM_Merged, без --write только расчёт и проверка), зависимости потоков на слитые моды переписываются на KMM_Merged, --install копирует KMM_Merged (не запускался). tools
elease.py safe оставляет KMM_Merged в mods.cfg (это чужие моды, а не наши правки).
- Бэкапы: backup	ools\{mods_cfg.py,kmm_build.py,release.py}.20261112_pre_merge, backup
ules\{excluded_mods.json,load_order.json}.20261112_pre_merge.
