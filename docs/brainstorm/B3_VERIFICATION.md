### Что нашлось при разборе (сверх известного)

1. Отчёт слеп к логам без метки времени. `since()` в session_report берёт только строки, начинающиеся с `YYYY-MM-DD HH:MM:SS`. В predators.log меток нет, поэтому он попал в «молчали за сессию», а в нём за эту сессию есть `smell api unavailable (zoneMgr/zoneSmell): nil -> smell off, fallbacks only`. Запах R4 в игре выключен, а отчёт показал маркеры по нулям. То же с chronicle.log: маркер `black_market` всегда 0.
2. Тесты пишут в живой logs/debug.log. KMM_Self.lua:682 пишет `KO hold: override registered at load` при загрузке модуля, до того как тест подставит путь лога из cfg. Получается 31 строка за прогон (всплески в 18:30, 18:31, 19:54, 20:01, 20:33, 20:40, 21:05). В окне сессии 17:51–19:44 все 83 строки «registered at load» и около 88 строк `KO hold/release` пришли от тестов. Значит, `[+]` у этого маркера в session_last.txt ложный. Тесты оставили следы и в deeds, fates, outlaws, stock, tempo.
3. Есть маркеры, которые не могут сработать никогда:
   - `KenshiLua.log` ищется в C:\KenshiModMap\logs, а лог лежит в 3817000612\logs;
   - `DIPLO_WORLD town=` (kmm_diplo.lua:366) и `world state loaded via` (KC.log) пишутся в KenshiLua.log, а маркер ищет их в debug.log;
   - подстрока `probe` в outlaws.log совпадает с чем угодно.
4. Маркеры считают подстроку и не смотрят на значение. `KO release ... asks=0` и `free containers 0, owned buildings 123` дают `[+]`, хотя по сути это провал.
5. В save_world.lua через REFM любой метод из справочника, которого нет в заглушке, тихо возвращает nil. Код уходит в фолбэк, тест зелёный. UNKNOWN печатается, но провалом не считается.
6. Примерно 90 тестов несут свои копии заглушек (ctypes + lua51.dll + inline Lua), общего движка-заглушки нет. Правку вроде «GameData nil запрещён» пришлось бы вносить в каждую копию.

### Отдельное правило lint (к И2 и И7): override только при загрузке — S
CallbacksReference помечает 212 override-колбэков (Category: Override / Interceptor). lua_lint должен считать ошибкой Events.on такого колбэка вне верхнего уровня файла (в функции, тике или повторном включении). Пример — повторная регистрация через ko_hook_on() из тика в KMM_Self.lua:504. Для каждого override обязателен счётчик вызовов в логе (`calls=`), его проверяет И7.

## Резюме
- Чаще всего тесты лгут не в логике, а в мире: заглушка мягче движка (nil, REFM no-op, пустой triggerCampaign), данные выдуманы (руины без фракции, ранги), порядок фиксирован.
